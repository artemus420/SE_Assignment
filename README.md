# Basic Number Calculator
This is a basic C++ program where you can input two integers and get computed output. Currently, it performs addition, but more functionality may be added in the future.

# How to Run in Dev-C++
1. Open Dev-C++.
2. Click File > Open, then select ProblemA.cpp.
3. Press F11 to compile and run.
4. Enter two integers in the console window.
